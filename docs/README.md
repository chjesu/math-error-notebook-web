## v0.2.0 产品基线

1. 用户可以使用中国大陆手机号和短信验证码注册、登录；系统必须具备防验证码轰炸能力。
2. 注册流程不得因“开放注册”被排除在 MVP 之外。
3. 注册完成后，用户必须创建一个家庭租户或通过邀请加入已有家庭租户，业务数据按租户隔离。
4. 邀请码仍然保留，但主要用于高权限角色授予和受控家庭加入，不作为普通用户注册的唯一入口。
5. 未成年人账号必须记录监护人同意关系；未完成同意前只能处于受限状态。
6. 手机号在界面、日志和运营查询中默认脱敏；用户可申请导出个人数据和注销账号。

## 状态定义

- `拟议`：尚未确认，不能直接进入开发。
- `已确认`：产品范围已确定，可进入技术设计和任务拆分。
- `开发中`：已有负责人领取并开始实施。
- `待验收`：实现完成，等待按 PRD 验收。
- `已完成`：验收证据齐全并通过。
- `已阻塞`：存在明确外部依赖，已记录责任人和解除条件。

## 变更规则

- 修改产品范围时，必须同步更新本文件、讨论纪要和 PRD 的版本号、日期、需求状态。
- 技术实现不得把邀请码重新变成普通用户注册的强制前置条件。
- “创建家庭”和“加入家庭”必须都能完成注册后的首次落位，不能产生无租户业务账号。
- 短信供应商、发送策略或合规要求变化时，需求编号保持稳定，在 PRD 的版本记录中补充变更。
