# 本地全功能版：桌面错题本复用与 Web 对齐基线

## 1. 目标

本地全功能版必须能在 `127.0.0.1` 上完成真实用户闭环：注册/登录、上传、确认题目与作答、记录完整错因、加入错题本、从已验证且已授权题库推荐、生成练习 PDF、记录练习/复习结果、查看掌握进度、导出个人数据和注销账号。

“本地运行”指 Web、MySQL、文件和 PDF 都在本机运行。使用 `--enable-codex-model` 后，Web 通过只读、临时的 Codex CLI 子进程处理已授权的数学图片或确认文本；不启用、模型失败或证据不足时使用完整手工确认与判题流程。题库维护继续调用桌面项目权威 CLI。

## 2. 复用边界

- 桌面唯一主库仍是 `math-error-notebook/data/math_notebook.db`，Web 不直接读取或共享运行时 SQLite。
- `scripts/migrate_question_bank.py` 通过桌面 `notebook.py` 只读抽取，经授权与验证双重质量门幂等同步到 Web MySQL。
- 推荐只使用 Web MySQL 中 `verified` 且来源为 `open` 或 `user_authorized` 的题；不把桌面 `verified` 或来源信誉直接等同于可推荐。
- 题库导入、来源修复、逐题审核、验证、检索索引维护继续复用桌面 `notebook.py`；Web 本地产品不建立第二套题库维护后台。
- PDF、复习间隔、推荐过滤和错题结构优先移植桌面项目已验证的规则，Web 继续使用个人 `user_id` 隔离的数据表和 API。

## 4. 本地验收门

1. `local_env.py status` 全部检查通过。
2. `local_env.py smoke` 能在已有账号和题库的数据库上运行，只创建并清理隔离测试账号，不删除现有用户或题库。
3. 题库同步预演与 MySQL 数量对账通过。
4. 全量单元/集成测试通过。
5. 浏览器以真实用户操作完成注册或登录、上传、确认、判题、入本、推荐、复习、PDF 和进度查看。
6. 所有新增数据库迁移可重复执行；用户已有数据不被重置。
