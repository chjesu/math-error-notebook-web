# 日历全日期统一展示

- 过去日期：当日到期、截至当天结束未完成、当日已完成；按中国日期计算。历史未完成包含当天及更早到期的题，不能沿用当前状态覆盖过去。
- 今天：今日到期、历史逾期（不含今天到期）、今日已完成。
- 未来日期：仅展示已安排的计划和阶段，不预测完成或逾期。
- 每个日期和各项数量可展开；保留新增与需改错入口。仍在当前待复习任务中的题可勾选加入今日选题草稿，最多 12 道；不改到期日期或复习阶段，不自动生成 PDF。

实现复用现有月历聚合、任务及完成记录和按账号/中国日期隔离的选题草稿。月度统计仍按事件所属日期计算；逐日未完成快照不累加到月度统计。后台只读取服务端确定的当前账号数据。

历史边界：旧版本重复同阶段会覆盖任务到期日期，部分导入记录也未保留完整到期历史。缺少证据时标记记录不完整，仅列出能确定的未完成题；不得将估算包装成精确历史或将缺失显示为 0。已移除错题继续遵循现有接口排除策略。本次不建立新复习状态机、不执行数据迁移、不改变认证。
