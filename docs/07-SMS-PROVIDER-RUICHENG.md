# 瑞成云短信通道接入说明

## 1. 实现状态

注册内核通过 `SmsSender` 协议隔离短信供应商，当前适配器为 `services/web_auth/ruicheng_sms.py`。它只使用 `POST application/x-www-form-urlencoded` 调用固定发送路径，连接超时 3 秒、读取超时 5 秒，不自动重试。

成功仅接受 `00,流水号` 或 `03,流水号`。这两个状态只表示网关受理，不表示手机已经收到。当前通道没有送达回调，系统不得伪造送达状态。

## 2. 服务器配置

凭据只允许通过服务器密钥配置注入：

```text
RUICHENG_SMS_USERNAME=<密钥配置引用>
RUICHENG_SMS_PASSWORD=<密钥配置引用>
RUICHENG_SMS_SIGNATURE=【已报备签名】
```

仓库、镜像、`.env` 示例、日志、异常、追踪和测试夹具均不得包含真实账号密码。曾经通过聊天、文档或工单明文传递的密码必须在上线前轮换。

## 3. 明文 HTTP 风险控制

服务商当前网关不支持 HTTPS，账号密码、手机号和验证码会经过明文 HTTP 链路。上线必须同时满足：

1. 阿里云应用服务器使用固定公网出口 IP，并由服务商只放行该 IP；
2. 安全组仅允许应用实例访问固定网关地址和端口；
3. 禁止代理自动跟随重定向，禁止从请求参数或租户配置覆盖网关地址；
4. APM、访问日志和抓包系统不记录短信 POST 请求体；
5. 优先要求服务商提供 HTTPS、专线或 VPN 接入；无法满足时将该风险记入上线审批。

## 4. 文案和风控约束

- 使用已报备签名和固定验证码模板，验证码有效期固定 300 秒；
- 总长度不超过 70 字，避免拆分计费；
- 同手机号至少间隔 60 秒，最多 5 条/小时且 5 条/日；
- 同时执行 IP、IP 前缀、设备、租户和全局预算限流；
- 超时属于结果未知，不自动重发；供应商拒绝信息只写安全状态码，不向用户暴露。

## 5. 上线验证

自动化测试使用注入的本地 transport，绝不连接真实网关。真实小流量测试必须由运维在密钥轮换、出口 IP 白名单和费用告警配置完成后执行，并使用专用测试号码；禁止对真实通道做并发压测。
