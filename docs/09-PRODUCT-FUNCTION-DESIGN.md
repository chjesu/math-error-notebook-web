# Web 版产品功能设计

> 文档版本：v0.3.1
> 基线日期：2026-08-22
> 状态：产品基线已确认；视觉稿与接口契约待后续工作项
> 上游：02-PRODUCT-REQUIREMENTS.md

## 1. 文档目的

本文把 PRD 转换成可以直接进行交互设计、接口拆分和验收的页面与流程规格。本文定义信息架构、页面责任、关键状态、异常恢复和产品事件；不代替视觉规范、API 契约或数据库设计。

## 2. 产品结构

### 2.1 普通用户导航

| 一级入口 | 页面 | 页面责任 |
|---|---|---|
| 工作台 | P-WORKBENCH | 汇总待确认、今日复习、处理中任务和近期进展 |
| 录入错题 | P-INTAKE-START、P-INTAKE-CONFIRM | 选择材料、上传、切分并确认题目和作答 |
| 错题本 | P-ERROR-LIST、P-ERROR-DETAIL | 查找、查看和维护正式错题 |
| 今日复习 | P-REVIEW-TODAY、P-REVIEW-ANSWER | 完成到期任务并更新复习阶段 |
| 练习与 PDF | P-PRACTICE、P-PDF-JOBS | 组织练习、生成和下载 PDF |
| 学习进度 | P-PROGRESS | 展示学生自身的趋势、薄弱点和完成情况 |
| 家庭与学生 | P-FAMILY、P-STUDENT、P-MEMBERS | 管理家庭、学生档案、监护和成员权限 |
| 设置与隐私 | P-SETTINGS、P-PRIVACY | 会话、安全、导出、注销和隐私说明 |

移动端一级导航只保留“工作台、录入、错题本、复习、更多”；其他入口位于“更多”。桌面端使用左侧导航。

### 2.2 运营后台

| 入口 | 页面责任 |
|---|---|
| 风控与短信 | 请求趋势、预算、熔断、告警和脱敏主体 |
| 任务中心 | 失败任务、重试资格、检查点和死信 |
| 内容审核 | 待验证题、来源、冲突和审核证据 |
| 判题复核 | 低置信度、复杂证明和用户申诉 |
| 数据权利 | 导出、注销、监护同意及保留处置工单 |
| 审计 | 高风险操作、临时权限和证据查询 |

运营后台与家庭产品使用独立导航、独立授权和显著环境标识。

## 3. 全局界面框架

### 3.1 当前作用域

所有学习页面顶部必须显示：

- 当前家庭；
- 当前学生；
- 监护/受限状态；
- 切换入口。

切换家庭或学生前，若存在未提交编辑，必须询问“保存草稿、放弃或取消切换”。切换完成后清空上一作用域的列表缓存、上传草稿引用和后台任务订阅，再加载新作用域。

### 3.2 全局任务中心

右上角任务入口展示处理中、待确认和失败任务数量。每项任务至少显示：

- 任务类型和创建时间；
- 当前状态；
- 所属学生；
- 已完成步骤；
- 数据是否已保存；
- 主操作。

任务中心不能只显示进度百分比。无法准确估计时显示当前步骤，不展示虚假的剩余时间。

### 3.3 通用反馈

| 类型 | 使用方式 |
|---|---|
| 页面提示 | 权限受限、监护待同意、推荐缺口等持续状态 |
| 字段错误 | 紧邻字段，说明修正方式，提交后聚焦第一个错误 |
| Toast | 已保存、已复制等短暂且可撤销影响 |
| 确认对话框 | 注销、撤回同意、成员移除、取消任务等高影响操作 |
| 结果页 | 上传完成、错题正式入本、导出已创建等流程终点 |

任何提示不得包含完整手机号、验证码、下载 token、对象键或供应商正文。

## 4. 开通与家庭落位

### 4.1 P-AUTH 手机验证

目标：在不泄露账号状态的前提下完成注册或登录。

界面：

- 手机号字段；
- 发送验证码；
- CAPTCHA 区域，仅在服务端要求时显示；
- 验证码字段和倒计时；
- 隐私说明入口。

规则：

- 发送后统一提示“如果请求符合条件，验证码将发送至该号码”。
- 倒计时是体验提示，不替代服务端冷却判断。
- 供应商结果未知时不得提示“未发送，可立即重试”。
- 刷新页面后根据服务端状态恢复冷却和挑战要求。

### 4.2 P-ROLE 账户身份选择

目标：区分成年人账号与学生账号，不询问“学生是否未成年”。

用户选择：

- 我是成年监护人/家庭负责人；
- 我是学生；
- 我是受邀教师或其他成年人。

所有学生均按未成年人处理。成年人可进入家庭创建或受邀加入；学生进入受限状态，只能接受监护邀请、绑定学生档案并等待同意。身份选择错误时必须通过受审计的更正流程处理，不能由客户端直接切换角色。

### 4.3 P-GUARDIAN 学生监护同意

学生侧显示：

- 当前为受限状态；
- 可以继续的操作；
- 监护邀请状态；
- 重新发送的服务端冷却；
- 更换监护联系路径。

成年监护人侧显示：

- 被监护学生最小必要信息；
- 政策版本与处理范围；
- 同意和不同意的影响；
- 撤回路径。

不得用预勾选、默认同意或把“继续使用”视为同意。

### 4.4 P-TENANT-PLACEMENT 家庭落位

该页面只对已验证成年人开放，成年人二选一：

1. 创建家庭：填写家庭显示名称并确认成为所有者；
2. 加入家庭：输入邀请码并预览将加入的家庭和角色。

邀请码验证失败使用稳定分类：无效、过期、已撤销、已用尽或不适用于当前账号；不得泄露不必要的家庭信息。

学生不进入该页面；学生通过监护邀请和学生档案绑定加入家庭，不能成为家庭所有者。

### 4.5 P-STUDENT-SETUP 学生档案建立

字段：

- 昵称/姓名；
- 年级（高一、高二、高三）；
- 当前学期，可跳过；
- 是否绑定当前登录用户；
- 监护关系状态。

学生档案只能由已验证的成年监护人创建，初始监护状态固定为 pending，不提供 not_required 选项。监护同意 active 后进入空工作台，主操作为“录入第一道错题”；未生效前进入受限说明页。

## 5. 工作台

### 5.1 页面优先级

从上到下按以下优先级展示：

1. 阻塞性状态：监护待同意、账号受限、需要重新验证；
2. 待用户确认：识别、判题或冲突；
3. 今日到期复习；
4. 处理中或失败任务；
5. 最近错题和学习进展；
6. 推荐缺口或题库补充提示。

页面只能有一个最强主操作。优先级相同时，先处理影响正式结果的确认，再处理到期复习。

### 5.2 空状态

| 场景 | 文案意图 | 主操作 |
|---|---|---|
| 无学生档案 | 先建立学习主体 | 创建学生档案 |
| 无错题 | 从一题开始，不夸大自动能力 | 录入第一道错题 |
| 无今日任务 | 今天已完成或暂无到期项 | 查看错题本 |
| 无合格推荐 | 明确缺口，不推荐低质量题 | 重做原题或稍后查看 |
| 全部任务失败 | 说明数据保存情况 | 查看失败任务 |

## 6. 错题录入向导

### 6.1 P-INTAKE-START 选择方式

提供四个入口：

- 拍摄单题与作答；
- 上传单题图片；
- 上传整份试卷；
- 手工录入。

在选择文件前展示允许格式、大小上限、材料用途和来源授权选择。

### 6.2 P-INTAKE-UPLOAD 上传

每个文件显示本地预览、大小、类型和上传状态。上传失败时：

- 网络失败：保留本地选择，允许重试；
- 类型或安全失败：不上传到解析，说明允许格式；
- 过大：提示压缩或拆分；
- 重复内容：允许打开已有任务，不创建重复记录。

### 6.3 P-INTAKE-SPLIT 试卷切分

桌面端使用左侧页缩略图、中间页面、右侧题目列表；移动端分为“页面—切分结果—逐题确认”三步。

用户操作：

- 调整题目区域；
- 合并跨页题；
- 拆分错误区域；
- 排除封面、答案页或空白页；
- 标记答案页；
- 保存草稿。

自动切分只是候选。进入下一步前显示题目数量并要求用户确认。

### 6.4 P-INTAKE-CONFIRM 内容确认

逐题展示：

- 原图区域；
- 题干、选项和公式候选；
- 学生作答候选；
- 题目来源；
- 清晰度和缺失提示。

主操作是“确认并分析”。修改任何影响语义的内容都会创建新输入版本。已开始分析时修改内容，必须说明旧结果将失效。

## 7. 判题与错题入本

### 7.1 P-GRADE-WAIT

处理页显示当前步骤：读取确认版本、分析作答、校验证据、等待确认。允许用户离开页面，任务在任务中心持续可见。

### 7.2 P-GRADE-RESULT

结果页按顺序展示：

1. 结论：正确、部分正确、错误或无法判断；
2. 第一处可证实的错误；
3. 证据：关联学生步骤和题目条件；
4. 错误阶段与错因候选；
5. 下一步行动；
6. 置信度和不确定项。

可用操作：

- 确认结果并加入错题本；
- 修正题干或作答；
- 补充步骤；
- 申请人工复核；
- 放弃本次分析。

“无法判断”不是错误页，必须给出重拍、补步骤或人工复核路径。

### 7.3 P-ERROR-COMMIT

确认前预览正式记录：学生、题目版本、判题、错因、标签和复习起点。提交幂等；成功页提供：

- 开始立即重做；
- 查看错题详情；
- 返回继续录入。

## 8. 错题本

### 8.1 P-ERROR-LIST

筛选：

- 状态；
- 年级和知识点；
- 错误阶段；
- 来源；
- 日期；
- 是否到期复习。

默认按“需要处理”排序，而不是简单按创建时间。列表卡显示题目摘要、首错步骤、状态、最近作答和下一复习时间。

### 8.2 P-ERROR-DETAIL

页面分区：

- 题目与来源；
- 历次作答时间线；
- 当前判题和错因；
- 推荐题；
- 复习阶段；
- 证据与版本；
- 管理操作。

移除错题前展示将取消的未来任务；历史作答默认保留。恢复后重新计算后续任务，不复制旧任务。

## 9. 推荐与复习

### 9.1 推荐卡

每张推荐卡必须解释：

- 来自哪道错题；
- 匹配的知识点/操作；
- 难度变化；
- 为什么现在推荐；
- 是否已做过。

不得展示“AI 推荐”作为唯一理由。没有合格题时展示缺口和可替代行动。

### 9.2 P-REVIEW-TODAY

顶部展示预计题数和预计耗时，允许调整今天数量。调整只是推迟，不是删除。

任务分组：

- 必做：到期且风险高；
- 建议：当天适合完成；
- 补充：用户主动添加。

### 9.3 P-REVIEW-ANSWER

默认一次只展示一道题。学生提交后进入与判题一致的确认流程，再显示阶段变化：

- 进入下一阶段；
- 保持当前阶段；
- 回退并安排更近复习；
- 等待复核。

不能仅因打开答案就标记完成。

## 10. 练习和 PDF

### 10.1 P-PRACTICE 练习篮

来源：

- 今日复习；
- 错题筛选；
- 推荐题；
- 用户手工选择。

生成前检查重复、来源授权、题目验证状态和数量。缺少合格题时允许生成较少题量并解释原因。

### 10.2 P-PDF-CONFIG

配置：

- 纸张固定 A4；
- 题目顺序；
- 每题留白；
- 是否单独生成答案版；
- 标题和日期；
- 默认不打印。

### 10.3 P-PDF-JOBS

显示 processing、ready、failed 和 expired。就绪后提供下载；权限变化、学生解绑或注销申请可能使旧链接失效，需要重新验证后生成。

## 11. 学习进度

只展示学生自身趋势：

- 新增错题和已掌握数量；
- 按知识点的错题与复习完成趋势；
- 各错误阶段分布；
- 到期与逾期任务；
- 推荐缺口；
- 最近 7/30 天活动。

禁止公开排名、跨学生比较和无法解释的固定能力标签。样本不足时显示“数据不足”，不生成结论。

## 12. 家庭、成员和权限

### 12.1 P-FAMILY

显示家庭名称、所有者、学生数量、成员数量和数据权利提示。解散家庭属于危险流程，需要二次验证、影响预览和复核。

### 12.2 P-MEMBERS

成员卡显示角色、学生作用域、权限范围、状态和最近变更。邀请时先选择角色，再选择学生和权限，最后预览邀请摘要。

教师默认只有指定学生的只读学习摘要；查看原图、添加任务或详细作答需要分别授权。

### 12.3 P-CONSENT

监护同意页显示政策版本、同意时间、覆盖学生、状态和撤回影响。撤回后立即进入受限状态，后台异步清理不影响权限立即关闭。

## 13. 设置、导出与注销

### 13.1 安全设置

- 当前会话和其他设备；
- 退出当前设备；
- 全端失效；
- 最近高风险操作；
- 手机号变更占位，未形成安全方案前不开放。

### 13.2 数据导出

创建前展示数据范围和不包含内容。状态为 pending、running、ready、failed 或 expired。下载时再次验证会话与权限。

### 13.3 注销

注销向导：

1. 二次身份验证；
2. 展示账号、家庭、学生、文件和任务影响；
3. 处理唯一所有者；
4. 取消或等待不可并发执行的任务；
5. 确认申请；
6. 展示处理状态和权利说明。

不得用一次按钮立即不可恢复删除所有家庭共享数据。

## 14. 运营和人工复核体验

### 14.1 最小信息

运营列表默认展示内部 ID、脱敏主体、任务类型、错误分类、时间和状态。不默认展示学生姓名、题目正文或原图。

### 14.2 临时访问

查看敏感材料必须选择工单、填写理由、限定时间，并留下访问审计。授权到期后页面和已有链接立即失效。

### 14.3 复核工作台

复核员看到冻结的审核包：题目版本、作答证据、候选、冲突和来源。提交前重新校验输入版本；已变化则拒绝提交并要求重新生成审核包。

## 15. 状态恢复设计

| 故障 | 用户看到 | 系统行为 | 用户操作 |
|---|---|---|---|
| 网络中断 | 已选择文件仍在，上传暂停 | 不创建重复正式文件 | 重试上传 |
| 解析失败 | 原文件已安全保存或明确已拒绝 | 保留检查点和错误分类 | 重拍、手工录入或放弃 |
| 模型超时 | 结果尚未产生，不显示猜测 | 最多按规则升级一次，不写正式库 | 稍后查看或人工复核 |
| 页面刷新 | 从服务端恢复任务和草稿 | 继续订阅现有任务 | 继续流程 |
| Worker 重启 | 任务仍显示处理中 | 从最近检查点接管 | 无需重复提交 |
| 权限被撤销 | 页面停止展示受限内容 | 取消后续副作用、链接失效 | 切换空间或联系管理员 |
| 内容版本变化 | 旧结果标记过期 | 创建新任务，不复用旧结论 | 重新确认并分析 |

## 16. 响应式与无障碍

- 360 px 宽度下主流程不出现水平滚动；公式和大图允许独立缩放。
- 所有操作可使用键盘完成，焦点顺序与视觉顺序一致。
- 状态不只依靠颜色表达；错误、成功和等待同时使用文字或图标。
- 上传、切分和公式确认提供可读标签及替代说明。
- 对话框打开后管理焦点，关闭后返回触发元素。
- 表单提交失败后提供错误摘要并聚焦第一个错误。
- 动画尊重减少动态效果设置。

## 17. 产品事件

| 事件 | 触发点 | 允许属性 |
|---|---|---|
| onboarding_completed | 家庭和学生落位完成 | 入口类型、耗时、是否监护流程 |
| intake_started | 选择录入方式 | 类型、文件数量 |
| intake_waiting_confirmation | 需要确认 | 原因分类、题目数量 |
| formal_error_created | 正式错题写入 | 错误阶段、是否复核，不含正文 |
| review_started/completed | 开始/完成复习 | 阶段、题数、耗时 |
| recommendation_gap | 无足够合格题 | 筛选维度和缺口数 |
| pdf_job_changed | PDF 状态变化 | 状态、题数、耗时 |
| privacy_request_changed | 导出/注销状态变化 | 类型、状态、耗时 |

所有事件遵循 PRD 的分析隐私规则。

## 18. 关键验收场景

1. 成年新用户注册、创建家庭和学生，上传单题，确认后形成正式错题并得到下一步。
2. 学生注册后只能等待监护关联；任一学生档案在监护同意前无法上传，同意后恢复，撤回后再次受限。
3. 整份试卷出现跨页题、答案页和模糊页，用户可修正切分并仅分析确认题目。
4. 判题为 unclear 时不创建正式错题，补充作答后创建新输入版本。
5. 推荐不足时展示缺口，所有已分配题均为 verified 且授权允许。
6. Worker 在解析、判题和 PDF 阶段分别中断，恢复后无重复记录或重复任务。
7. 用户切换学生时，列表、草稿、对象链接和任务订阅不串号。
8. 教师只能看到被授权学生和字段，撤销后旧链接立即失效。
9. 导出包不包含其他成员私有数据；过期链接不能访问。
10. 唯一家庭所有者注销时被要求先转移或解散，不能留下无所有者家庭。

## 19. 后续设计产物

进入前端实现前还需形成：

- 页面线框与视觉规范；
- OpenAPI 契约和稳定错误码；
- 权限策略测试表；
- 复习阶段与数学领域规则配置；
- 内容审核规范和固定基准集；
- 合规批准的数据保留分类表；
- 分任务 SLO 与监控面板。

这些产物不能改变 PRD 的安全边界；如需改变产品范围，必须先升级产品基线。
