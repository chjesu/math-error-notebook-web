# ADR-004：学习事实视图与练习模式

- 状态：已接受
- 日期：2026-08-30
- 范围：Phase 5 错因筛选、学习画像、推荐和练习 PDF

## 决策

继续以批改候选中的已校验诊断 JSON 作为错因与知识点事实源。错因描述学生某次作答为什么出错，因此归属于错题记录关联的批改候选；题目只保留题干、答案、解析、年级和难度，不增加未经来源证明的永久错因标签。

MySQL 8 增加两个只读、调用者权限运行的视图：错题学习事实视图提取标准错因，知识点学习事实视图通过 `JSON_TABLE` 展开知识点。应用查询仍必须带当前会话 `user_id`，视图本身不承担授权。

推荐以原错题文本和候选题文本的共同要素作为上下文相关度，再在相关候选中优先选择高于原题且增幅最小的难度。当前错因用于生成训练目标说明，不写入候选题。原题或候选题缺少难度时保持可推荐，但不声称完成了难度递进。

练习 PDF 使用显式 `mode`：`review` 输出错因、知识点、解析与参考答案，`self_test` 只输出题目和作答留白。旧 `include_answers` 请求仅作为迁移兼容；若它与 `mode` 冲突，请求返回校验错误。任务幂等摘要包含规范化后的 `mode`。

## 不变量与失败语义

- 只统计未删除且归属于当前用户的错题；跨用户对象继续返回不存在。
- 只接受现有 12 个标准错因码；未知错因和未知 PDF 模式在边界失败关闭。
- JSON 无效或旧数据缺少诊断时不猜测错因与知识点，也不阻断该错题的普通展示。
- 同一错题内重复知识点只计一次；雷达分数是当前用户样本内的相对强度，不解释为能力测评分数。
- 推荐继续排除已做题、未验证题和无授权题；递进排序不能绕过这些资格门槛。
- 自测卷不包含错因、推荐理由、解析或答案，避免提示泄漏。

## 威胁模型

- 欺骗：用户身份只来自服务端会话，不接受请求体中的 `user_id`。
- 篡改：错因和 PDF 模式使用枚举白名单；题目和错题标识继续由仓储核验归属。
- 信息泄露：聚合、列表、任务和下载查询均按用户过滤；自测模板不渲染诊断和答案。
- 注入：筛选值只作为参数化查询参数，不能改变 SQL、视图名或排序表达式。
- 拒绝服务：画像返回固定上限的错因和知识点，推荐候选和 PDF 错题数量沿用既有限制。

## 非目标

- 本阶段不导入新的外部题库知识标签，也不使用模型在线决定推荐结果。
- 本阶段不把画像分数解释为考试成绩、掌握度或心理测量结论。
- 本阶段不改变认证、短信、文件存储或生产部署。
