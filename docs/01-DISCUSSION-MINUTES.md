# Web 版讨论纪要

> 文档版本：`v0.3.1`
> 会议/确认日期：`2026-08-22`
> 状态：`已确认`
> 适用范围：李兆霖数学错题本多用户 Web 版 MVP

## 1. 讨论目标

明确多用户 Web 版的注册方式、家庭租户归属、未成年人保护、错题学习闭环、内容质量门、邀请码边界以及个人信息权利，作为架构设计、任务拆分和验收的统一输入。

## 2. 已确认决策

### DEC-001：开放注册纳入 MVP

- 决策：普通用户可以直接使用手机号和短信验证码完成注册或登录。
- 影响：删除“开放注册不属于 MVP”的旧边界；邀请码不再是普通注册的必要条件。
- 对应需求：`AUTH-001`、`AUTH-002`。
- 状态：已确认。

### DEC-002：验证码发送必须内建防轰炸机制

- 决策：验证码发送前执行手机号、IP、设备、会话等维度的限频和风险判断；发送接口无论号码是否已注册，都返回不泄露账号状态的统一结果。
- 影响：必须把发送频率、每日上限、失败次数、图形/行为验证升级、供应商异常降级和审计记录纳入设计。
- 对应需求：`AUTH-002`。
- 状态：已确认。

### DEC-003：家庭是首个业务租户

- 决策：成年新用户完成身份注册后可创建家庭租户或通过有效邀请加入；学生只能通过监护邀请/档案绑定加入，不能创建家庭。
- 影响：学习档案、错题、复习任务、监护关系和成员权限均按 `tenant_id` 隔离；不得依赖客户端传入的租户 ID 直接授权。
- 对应需求：`TENANT-001`、`TENANT-002`。
- 状态：已确认。

### DEC-004：邀请码保留，但用途收窄

- 决策：邀请码用于受控加入家庭，以及授予监护人、教师、运营管理员等高权限角色；已验证成年人创建家庭不需要邀请码，学生不能创建家庭。
- 影响：邀请码必须一次性或限次、限时、绑定预期租户和角色，并支持撤销及审计。
- 对应需求：`AUTHZ-001`、`TENANT-002`。
- 状态：已确认。

### DEC-005：所有学生均为未成年人并需要监护人同意

- 决策：学生角色一律按未成年人处理，不设计成年学生或学生无需监护同意的分支；成年人账号只能承担监护人、家庭所有者、教师等角色。
- 影响：首次开通选择账户身份而不是判断“学生是否未成年”；所有学生档案初始监护状态为 pending，同意 active 前不得上传错题、生成学习画像或执行其他持续性个人数据处理。
- 对应需求：`AUTH-003`。
- 状态：已确认。

### DEC-006：隐私权利进入 MVP

- 决策：手机号默认脱敏；用户可以导出其有权访问的数据，并可以申请注销账号。
- 影响：导出和注销必须异步、可审计、可重试；注销前处理家庭所有权转移、未完成订单/纠纷、法定留存及共享数据边界。
- 对应需求：`PRIV-001`、`PRIV-002`、`PRIV-003`。
- 状态：已确认。

### DEC-007：公开 MVP 必须同时通过账号门和学习闭环门

- 决策：注册链路属于产品基础，但不能单独构成公开 MVP；公开 MVP 必须同时具备安全的账号/租户基础和从错题录入到复习 PDF 的学习闭环。
- 影响：工程可以分批验收，但对外完成状态只能在两道门均有证据后更新。
- 对应需求：全部 P0 需求。
- 状态：已确认。

### DEC-008：学生档案是学习数据的最小作用域

- 决策：家庭可包含多个学生档案；每个档案只属于一个家庭，所有文件、作答、错题、推荐和复习任务都必须明确绑定学生。
- 影响：家庭成员身份不能自动换算成全部学生数据权限；教师和家庭所有者仍需按学生获得授权。
- 对应需求：`STUDENT-001`。
- 状态：已确认。

### DEC-009：识别、判题和错因必须先确认后入本

- 决策：OCR、切分、判题和错因均为候选；题干与作答先由用户确认，正式错题再由确定性质量门提交。
- 影响：输入修改创建新版本并使旧分析失效；低置信度、图像不清和答案冲突进入待确认或人工复核。
- 对应需求：`INTAKE-002`、`GRADE-001`、`ERROR-001`、`JOB-001`。
- 状态：已确认。

### DEC-010：推荐只使用已验证且授权允许的题

- 决策：推荐数量不足时展示缺口，不以未验证、来源不明、授权不允许或重复题凑数。
- 影响：题目来源、版本、验证状态和授权范围成为推荐前置质量门。
- 对应需求：`CONTENT-001`、`RECOMMEND-001`、`REVIEW-001`。
- 状态：已确认。

### DEC-011：用户授权的私有试题不跨租户复用

- 决策：用户上传的试卷和题目默认只服务当前租户；只有开放来源或获得平台分发授权的内容，经过审核后才能进入公共已验证题库。
- 影响：内容去重不能自动扩大使用范围，迁移和审核必须保留来源及授权证据。
- 对应需求：`INTAKE-001`、`CONTENT-001`。
- 状态：已确认。

### DEC-012：任务失败必须可恢复且对用户可解释

- 决策：解析、判题、推荐、导出和 PDF 作为可恢复任务；用户必须看到当前步骤、数据是否保存以及可采取的下一步。
- 影响：刷新、重复提交、Worker 重启和网络重试不得制造重复扣费或重复正式记录。
- 对应需求：`JOB-001`、`WORKBENCH-001`、`PDF-001`。
- 状态：已确认。

## 3. MVP 范围

### 已纳入

- 手机号短信验证码注册与登录。
- 验证码限流、风险升级、统一响应和发送审计。
- 成年人注册后创建家庭或受控加入；学生通过监护邀请和档案绑定加入。
- 所有学生必需的监护同意和受限状态。
- 邀请码的家庭加入与高权限授予。
- 手机号脱敏、个人数据导出、账号注销。
- 家庭租户的数据隔离和最小权限控制。
- 学生档案与按学生授权。
- 单题、作答和整卷采集，以及手工录入兜底。
- 题目切分、内容确认、判题、首错步骤和正式错题本。
- 只基于已验证题的推荐、分阶段复习与 A4 PDF。
- 学习工作台、异步任务状态、失败恢复和最小运营复核。

### 本次仍不纳入

- 海外手机号及国际短信。
- 用户名/密码注册。
- 第三方社交账号登录。
- 多学校、多机构的复杂组织树及商业结算。
- 自动判断法定监护关系的外部实名核验。
- 多学校/机构组织树、商业结算、公开题库市场和学生社区。
- 由模型自动提交正式判题、正式题库、权限变更或生产发布。
- 向其他租户复用仅有用户授权的私有试题。

上述“不纳入”不能被解释为排除普通用户开放注册。

## 4. 关键业务口径

| 主题 | 统一口径 |
|---|---|
| 注册与登录 | 同一手机号验证码流程；首次验证成功创建身份，已有身份则登录 |
| 手机号唯一性 | 规范化后的手机号全局唯一；数据库仅保存必要形式，展示一律脱敏 |
| 家庭归属 | 成年人可创建或加入家庭；学生只能通过监护邀请/档案绑定加入，监护同意 active 后才能进入完整工作台 |
| 学生 | 一律为未成年人；同意未完成时只允许完成监护邀请、档案绑定、退出登录、隐私说明等必要操作 |
| 邀请码 | 与租户、角色、有效期、使用次数绑定；高权限邀请码不得通用或永久有效 |
| 注销 | 先验证身份，再检查租户所有权和法定留存；完成后令牌失效并停止非必要处理 |
| 导出 | 只导出当前用户依法且按租户权限可访问的数据；提供时限和下载过期机制 |
| 学生作用域 | 家庭可有多个学生；每项学习数据必须绑定学生，家庭角色不自动获得全部学生权限 |
| 错题入本 | 题干、作答与判题先确认；候选不能直接成为正式错题 |
| 推荐 | 只使用已验证且授权允许的题；不足时显示缺口 |
| 复习 | 任务变化必须可追溯到作答或人工操作，不静默删除到期任务 |
| 任务恢复 | 从最近检查点继续；输入变化创建新任务，不复用旧候选 |

## 5. 风险及处理原则

| 风险 | 处理原则 | 关联需求 |
|---|---|---|
| 短信轰炸造成费用与骚扰 | 多维限流、渐进挑战、黑名单、单日预算和熔断 | AUTH-002 |
| 枚举已注册手机号 | 发送与校验接口使用统一响应，不暴露账号存在性 | AUTH-001、AUTH-002 |
| 学生绕过同意 | 所有学生档案强制 pending/active/revoked，监护同意前不开放核心数据处理 | AUTH-003 |
| 越权进入其他家庭 | 服务端根据成员关系解析租户，不信任客户端声明 | TENANT-001、TENANT-002 |
| 邀请码泄露 | 短时、限次、哈希保存、撤销、审计及角色上限 | AUTHZ-001 |
| 手机号泄露 | 默认脱敏、日志清洗、字段加密/访问控制和审计 | PRIV-001 |
| 注销误删家庭共享数据 | 区分个人数据与家庭共享数据，先转移所有权或解散租户 | PRIV-003 |

## 6. 待专项负责人批准的策略配置

以下不改变产品范围，可继续本地开发，但在生产部署批准前必须由表中负责人冻结版本并附证据：

| 配置 | 负责人 | 退出条件 |
|---|---|---|
| 短信模板、预算、固定出口和供应商故障流程 | SEC + SRE | 小流量验证、熔断和回滚证据 |
| 手机号保护、密钥托管和检索指纹 | SEC + DATA | 威胁审查和密钥权限演练 |
| 监护同意文本、通知路径和证据保留 | PO + 合规 | 版本化政策与撤回演练 |
| 数据导出格式和下载有效期 | PO + SEC | 越权、过期和可读性验收 |
| 注销冷静期与各类数据处置 | 合规 + DATA | 可执行数据分类表和删除证明 |
| 复习阶段、间隔和掌握规则 | PO + MATH | 固定样本回归和版本记录 |
