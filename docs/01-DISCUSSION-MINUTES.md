# Web 版讨论纪要

> 文档版本：`v0.2.0`
> 会议/确认日期：`2026-08-22`
> 状态：`已确认`
> 适用范围：李兆霖数学错题本多用户 Web 版 MVP

## 1. 讨论目标

明确多用户 Web 版的注册方式、家庭租户归属、未成年人保护、邀请码边界以及个人信息权利，作为架构设计、任务拆分和验收的统一输入。

## 2. 已确认决策

### DEC-001：开放注册纳入 MVP

- 决策：普通用户可以直接使用手机号和短信验证码完成注册或登录。
- 影响：删除“开放注册不属于 MVP”的旧边界；邀请码不再是普通注册的必要条件。
- 对应需求：`AUTH-001`、`AUTH-002`。
- 状态：已确认。

### DEC-002：验证码发送必须内建防轰炸机制

- 决策：验证码发送前执行手机号、IP、设备、会话等维度的限频和风险判断；发送接口无论号码是否已注册，都返回不泄露账号状态的统一结果。
- 影响：必须把发送频率、每日上限、失败次数、图形/行为验证升级、供应商异常降级和审计记录纳入设计。
- 对应需求：`AUTH-002`。
- 状态：已确认。

### DEC-003：家庭是首个业务租户

- 决策：新用户完成身份注册后，必须二选一：创建家庭租户，或通过有效邀请加入已有家庭租户。
- 影响：学习档案、错题、复习任务、监护关系和成员权限均按 `tenant_id` 隔离；不得依赖客户端传入的租户 ID 直接授权。
- 对应需求：`TENANT-001`、`TENANT-002`。
- 状态：已确认。

### DEC-004：邀请码保留，但用途收窄

- 决策：邀请码用于受控加入家庭，以及授予监护人、教师、运营管理员等高权限角色；普通学习者创建家庭不需要邀请码。
- 影响：邀请码必须一次性或限次、限时、绑定预期租户和角色，并支持撤销及审计。
- 对应需求：`AUTHZ-001`、`TENANT-002`。
- 状态：已确认。

### DEC-005：未成年人需要监护人同意

- 决策：注册时采集满足业务所需的年龄段/未成年人声明，而非默认收集完整身份证信息；未成年人账号须建立监护人同意记录。
- 影响：同意完成前账号处于受限状态，不得上传错题、生成学习画像或执行其他持续性个人数据处理；监护人可查看和撤回同意。
- 对应需求：`AUTH-003`。
- 状态：已确认。

### DEC-006：隐私权利进入 MVP

- 决策：手机号默认脱敏；用户可以导出其有权访问的数据，并可以申请注销账号。
- 影响：导出和注销必须异步、可审计、可重试；注销前处理家庭所有权转移、未完成订单/纠纷、法定留存及共享数据边界。
- 对应需求：`PRIV-001`、`PRIV-002`、`PRIV-003`。
- 状态：已确认。

## 3. MVP 范围

### 已纳入

- 手机号短信验证码注册与登录。
- 验证码限流、风险升级、统一响应和发送审计。
- 注册后创建家庭或受控加入家庭。
- 未成年人监护人同意和受限状态。
- 邀请码的家庭加入与高权限授予。
- 手机号脱敏、个人数据导出、账号注销。
- 家庭租户的数据隔离和最小权限控制。

### 本次仍不纳入

- 海外手机号及国际短信。
- 用户名/密码注册。
- 第三方社交账号登录。
- 多学校、多机构的复杂组织树及商业结算。
- 自动判断法定监护关系的外部实名核验。

上述“不纳入”不能被解释为排除普通用户开放注册。

## 4. 关键业务口径

| 主题 | 统一口径 |
|---|---|
| 注册与登录 | 同一手机号验证码流程；首次验证成功创建身份，已有身份则登录 |
| 手机号唯一性 | 规范化后的手机号全局唯一；数据库仅保存必要形式，展示一律脱敏 |
| 家庭归属 | 完成注册不等于完成业务开通；必须创建或加入家庭后才能进入完整工作台 |
| 未成年人 | 同意未完成时只允许完成监护邀请、退出登录、隐私说明等必要操作 |
| 邀请码 | 与租户、角色、有效期、使用次数绑定；高权限邀请码不得通用或永久有效 |
| 注销 | 先验证身份，再检查租户所有权和法定留存；完成后令牌失效并停止非必要处理 |
| 导出 | 只导出当前用户依法且按租户权限可访问的数据；提供时限和下载过期机制 |

## 5. 风险及处理原则

| 风险 | 处理原则 | 关联需求 |
|---|---|---|
| 短信轰炸造成费用与骚扰 | 多维限流、渐进挑战、黑名单、单日预算和熔断 | AUTH-002 |
| 枚举已注册手机号 | 发送与校验接口使用统一响应，不暴露账号存在性 | AUTH-001、AUTH-002 |
| 未成年人绕过同意 | 服务端状态机限制，监护同意前不开放核心数据处理 | AUTH-003 |
| 越权进入其他家庭 | 服务端根据成员关系解析租户，不信任客户端声明 | TENANT-001、TENANT-002 |
| 邀请码泄露 | 短时、限次、哈希保存、撤销、审计及角色上限 | AUTHZ-001 |
| 手机号泄露 | 默认脱敏、日志清洗、字段加密/访问控制和审计 | PRIV-001 |
| 注销误删家庭共享数据 | 区分个人数据与家庭共享数据，先转移所有权或解散租户 | PRIV-003 |

## 6. 待技术设计确认项

以下不改变产品范围，由技术设计给出实现选型：

1. 短信服务商主备方案、签名与模板审核流程。
2. 分布式限流存储和验证码短期状态存储方案。
3. 手机号字段加密、密钥托管和检索指纹方案。
4. 监护人同意通知的短信/站内路径及证据留存周期。
5. 数据导出的文件格式、对象存储和下载有效期。
6. 注销冷静期及依法必须保留的数据清单。
