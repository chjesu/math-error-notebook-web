## 交付口径

本版本只面向个人错题本：没有家庭、成员、身份、角色、昵称、年级、学生档案、监护或实名步骤。目标认证接口为：

1. `POST /v1/auth/login/otp/request`
2. `POST /v1/auth/login/otp/verify`
3. `POST /v1/auth/register/otp/request`
4. `POST /v1/auth/register/complete`

注册完成必须在一个事务中消费验证码、保存密码凭据和协议版本、创建账号及会话；登录不得建号，注册不得覆盖已有账号。导出和注销必须敏感 OTP 二次验证。接口文档、实现、迁移、真实 MySQL 和浏览器 E2E 已在本地候选中对齐。
