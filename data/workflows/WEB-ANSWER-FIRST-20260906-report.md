# 正确答案不强制补写过程

## 已确认规则与范围

- 用户明确确认：解答题的最终答案正确但没有过程，也判正确；补写过程只作为建议。选择题和填空题同样适用。
- 区分学生作答与模型参考解析：保留模型独立解题的完整解析要求，但不能要求学生补写来满足模型工具字段。
- 不因缺少过程降级、重复入本或阻断 PDF 关联、复习完成；真实错答、漏答、歧义和未完成的证明仍正常处理。不臆造学生步骤，不批量覆盖历史判定。
- 根因是判题提示未明确答案优先与两类过程的区别；现有业务提交按 verdict 驱动，没有学生过程长度门禁。采用现有提示、工具契约与状态机，不新增模型调用或数据库表。
- 使用项目工作流记录步骤；工程路由仅本地 route 查询，未外发工程代码、图片、密钥或数据库记录。
