范围：本机模拟 ECS 客户端/服务端边界；不部署 ECS，不发送真实短信，不外发代码审查包，不改变既有用户学习数据。

## 完成内容

- 处理工作区未完成合并，清除运行源码中的冲突标记；保留既有复习码关联、订正、延期学习、Token 计量、PDF 数学排版和会话工具链。
- 浏览器统一访问 `http://127.0.0.1:8000/`，由 Python 网关转发 Harness 页面、静态资源、插件、HTTP API 与 WebSocket。业务插件使用 `window.location.origin`，不依赖固定浏览器内部端口。
- 网关沿用确定性会话、Host 与 Origin 验证，过滤跨边界 Cookie/身份头；内部 Host 仅绑定随机回环端口。注册状态机未改变。
- 启动检查插件 JavaScript 与配置合并标记；后台启动等待健康响应，脚本传递失败退出码。PID 身份校验与进程树回收由原启动器统一负责。
- 移除合并重复引入的 DeepSeek 默认 Provider 配置；保留产品现用 Qwen 默认模型与 `DASHSCOPE_API_KEY` 变量。运行检查只输出配置名称和“密钥存在”布尔值，没有输出密钥。
- 修复“需改错”计数在延期过滤后漏掉 PDF 单题活动的问题；订正历史与复习阶段不被重写。
- 新的批次 API、租约与存储适配代码作为合并内容保留；没有替换现有 Harness“冻结转录→提交判题→按权威回执关联”的默认流程。
